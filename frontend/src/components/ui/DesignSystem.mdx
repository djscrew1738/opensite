# OpenSite Design System

## "Dark Forge" Aesthetic

The OpenSite design system uses a dark-themed industrial aesthetic optimized for outdoor/field use with high contrast and reduced eye strain.

## Component Patterns

### Button Hierarchy

1. **Primary**: Main action, use sparingly
2. **Secondary**: Alternative actions
3. **Danger**: Destructive actions
4. **Ghost**: Low emphasis, icon buttons
5. **Link**: Navigation-like actions

### Card Patterns

- Use `AccessibleCard` for all interactive cards
- Always provide `ariaLabel` for interactive cards
- Group related actions within card footer

### Modal Guidelines

- Always use `useFocusTrap` for accessibility
- Lock body scroll with `useScrollLock`
- Provide clear close actions
- Use consistent header/footer layout

---

## Accessibility Standards

### WCAG 2.1 AA Compliance

- All interactive elements keyboard accessible
- Focus indicators visible
- Color contrast ratio ≥ 4.5:1 for text
- Icon buttons have `aria-label`
- Forms have proper label association

### Mobile Considerations

- Swipe gestures for common actions
- Bottom sheet pattern for mobile modals
- Touch targets ≥ 48px
- Reduced motion support

## Best Practices

1. **Always use design tokens** - No arbitrary values
2. **Prefer composition** - Use subcomponents (Card.Header, etc.)
3. **Accessibility first** - Test with keyboard and screen reader
4. **Mobile-aware** - Design for touch, test on devices
5. **Consistent patterns** - Reuse established patterns
